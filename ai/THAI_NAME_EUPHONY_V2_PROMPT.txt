ประเมินความไพเราะ ความไหลลื่น และความง่ายในการออกเสียงของชื่อภาษาไทยนี้

ชื่อ: {{name}}

คุณต้องตอบเป็น JSON object เท่านั้น
ห้ามมี markdown
ห้ามมี code block
ห้ามมีคำอธิบาย
ห้ามมีข้อความก่อนหรือหลัง JSON
ห้ามมี field อื่นนอก schema ที่กำหนด
ถ้าไม่แน่ใจ ให้เลือกค่าที่ conservative และยังคง valid ตาม schema

schema ที่ต้องใช้:
{
  "score": {
    "overall": 0,
    "pronunciation_ease": 0,
    "euphony": 0,
    "rhythm": 0
  },
  "labels": [],
  "summary": "",
  "issues": [],
  "style_tone": []
}

หลักการประเมิน:
- ประเมินเฉพาะ "เสียง" และ "จังหวะการอ่าน"
- ห้ามพิจารณาความหมาย ความมงคล ความนิยม บุคลิก ภาพลักษณ์ หรือความสวยของตัวสะกด
- overall = ภาพรวมด้านเสียง
- pronunciation_ease = อ่านออกเสียงครั้งแรกง่ายแค่ไหน
- euphony = ฟังนุ่ม รื่นหู หรือแข็ง
- rhythm = จังหวะต่อเนื่องหรือสะดุด

allowed_labels:
[
  "เสียงลื่น",
  "ออกเสียงง่าย",
  "ฟังนุ่ม",
  "เสียงค่อนข้างแข็ง",
  "จังหวะสมดุล",
  "จังหวะสะดุดเล็กน้อย",
  "ฟังคลาสสิก",
  "ฟังร่วมสมัย",
  "จำง่าย",
  "มีเอกลักษณ์"
]

ข้อบังคับ:
1. labels ต้องเลือกจาก allowed_labels เท่านั้น
2. ห้ามใช้ label อื่นโดยเด็ดขาด
3. labels ต้องมี 2 ถึง 4 ค่า
4. ถ้าชื่อมีเสียงแข็ง อ่านสะดุด พยัญชนะชนกันมาก โครงเสียงตัดกัน หรืออ่านครั้งแรกไม่ลื่น ต้องมีอย่างน้อย 1 ค่า:
- "เสียงค่อนข้างแข็ง"
หรือ
- "จังหวะสะดุดเล็กน้อย"
5. ถ้าชื่ออ่านลื่นชัดเจน ห้ามใส่:
- "เสียงค่อนข้างแข็ง"
- "จังหวะสะดุดเล็กน้อย"
6. summary ต้องเป็นภาษาไทย 1 ประโยคสั้นเท่านั้น
7. summary ต้องพูดเฉพาะเรื่องเสียงและจังหวะ
8. issues ต้องเป็น array
9. issues ใส่ได้ไม่เกิน 2 ข้อ
10. ใส่ issues เฉพาะเมื่อมีจุดสะดุดหรือจุดที่ทำให้อ่านยากจริง
11. ถ้าไม่มีปัญหาให้ใส่ []
12. style_tone ต้องเป็น array ของคำสั้นภาษาไทย
13. style_tone ต้องมี 1 ถึง 3 ค่า
14. คะแนนทุกช่องต้องเป็นจำนวนเต็ม 0 ถึง 100
15. ห้ามให้คะแนนสูงเกินจริง ถ้าชื่อกลางๆ ให้คะแนนกลาง
16. ถ้าชื่อออกเสียงยากจริง pronunciation_ease ต้องไม่สูง
17. ถ้าชื่อจังหวะสะดุด rhythm ต้องไม่สูง
18. ถ้าชื่อโทนเสียงแข็ง euphony ต้องไม่สูง

แนวทางให้คะแนนแบบ conservative:
- 85-100 = ลื่นมาก เด่นชัด อ่านง่ายมาก
- 70-84 = ดีค่อนข้างลื่น มีติดเล็กน้อยได้
- 55-69 = กลางๆ ไม่แย่แต่ไม่ลื่นเด่น
- 40-54 = มีความแข็งหรือสะดุดค่อนข้างชัด
- 0-39 = อ่านยากหรือสะดุดชัดเจนมาก

heuristics:
- ถ้าอ่านต่อเนื่องง่ายและไม่มีช่วงเสียงหัก ให้ pronunciation_ease และ rhythm สูงขึ้น
- ถ้ามีพยัญชนะหนัก เสียงกระแทก หรือจังหวะไม่ต่อเนื่อง ให้ลด euphony และ rhythm
- ถ้าชื่อสั้น อ่านตรงไปตรงมา อาจใช้ "ออกเสียงง่าย" หรือ "จำง่าย"
- ถ้าชื่อมีโครงเสียงเด่นแปลกกว่าทั่วไป แต่อ่านได้อยู่ อาจใช้ "มีเอกลักษณ์"
- ถ้าชื่อให้ความรู้สึกไทยดั้งเดิมหรือเป็นทางการ อาจใช้ "ฟังคลาสสิก"
- ถ้าชื่อฟังสั้น กระชับ หรือโมเดิร์น อาจใช้ "ฟังร่วมสมัย"

กฎกันความลำเอียง:
- อย่า default ไปทางชม
- อย่าใส่ "เสียงลื่น" ถ้ายังมีความสะดุดชัด
- อย่าใส่ "ออกเสียงง่าย" ถ้าอ่านครั้งแรกมีโอกาสลังเล
- อย่าใส่ issues ถ้าไม่มีปัญหาจริง
- อย่าขัดแย้งกันเอง เช่น ใส่ทั้ง "เสียงลื่น" และ "จังหวะสะดุดเล็กน้อย" เว้นแต่เป็นกรณีก้ำกึ่งจริง
