    • 1. Name Search

    POST /api/v1/name-search

    ค้นหาชื่อตามความหมาย (Vector Search) พร้อมกรองเลขศาสตร์, พลังเงา, กาลกิณี และคืนข้อมูล per-character highlighting

    Request Body (JSON)

    Field Type Required Description
    keyword string required ความหมายที่ต้องการ เช่น "กล้าหาญ", "ร่ำรวย"
    day string optional วันเกิด เช่น "Monday", "Tuesday" (ดูตาราง)
    lastname string optional ชื่อที่ต้องการ Matching (เช่น นามสกุล) เพื่อคำนวณผลรวมใหม่
    filter_sat bool optional กรองเฉพาะเลขศาสตร์ดี (default: true)
    filter_sha bool optional กรองเฉพาะพลังเงาดี (default: true)
    filter_kaki bool optional กรองชื่อที่มีกาลกิณีออก (default: true)
    limit int optional จำนวนผลลัพธ์ 1-100 (default: 50)
    similar_mode bool optional โหมดรวมชื่อ (Matching) — ใช้ Lastname ช่วยดึงแนวทางความหมายจาก Vector (default: false)

    Request Example

    {
    "keyword": "กล้าหาญ",
    "lastname": "ทองแสน",
    "day": "Monday",
    "filter_sat": true,
    "filter_sha": true,
    "filter_kaki": false,
    "limit": 10
}

    Response Body (JSON)

    Field Type Description
    success bool true = สำเร็จ, false = ล้มเหลว
    error object|null จะมีเมื่อ success=false (ตัวอย่าง: {"message": "..."})
    total int จำนวนผลลัพธ์ทั้งหมด
    results array รายการชื่อ (ดูด้านล่าง)
    kaki_info object|null ข้อมูลกาลกิณีของวันที่เลือก (null ถ้าไม่ระบุวัน)

    results[] Object

    Field Type Description
    name string ชื่อภาษาไทย
    meaning string ความหมายของชื่อ
    sat_sum int ผลรวมเลขศาสตร์
    sha_sum int ผลรวมพลังเงา
    total_sat int ผลรวมศาสตร์ เมื่อรวมกับ Matching Name
    total_sha int ผลรวมพลังเงา เมื่อรวมกับ Matching Name
    distance float ระยะห่าง Vector (0 = ตรงมาก, 1 = ไกล)
    is_sat_good bool เลขศาสตร์ดีหรือไม่
    is_sha_good bool พลังเงาดีหรือไม่
    is_total_sat_good bool ผลรวมสะสม (Matching) ดีหรือไม่
    is_total_sha_good bool พลังเงาสะสม (Matching) ดีหรือไม่
    kaki_highlight array อักษรทีละตัว + สถานะกาลกิณี ([] ถ้าไม่ระบุวัน)

    kaki_highlight[] Object

    Field Type Description
    char string ตัวอักษร 1 ตัว (Unicode code point)
    is_kaki bool true = กาลกิณี (แสดงสีแดง)

    kaki_info Object

    Field Type Description
    day string วันเกิด (English)
    day_th string วันเกิด (ภาษาไทย)
    description string คำอธิบายกาลกิณีของวัน
    kaki_chars string[] รายการตัวอักษรกาลกิณีทั้งหมด

    3. Kaki Highlight — การแสดงสีแดงบน Mobile

    ใช้ kaki_highlight array เพื่อ render ชื่อแบบ per-character coloring:

    อีกหาญตระกูล
    💡 สำคัญสำหรับ Mobile:
    บน Mobile (Android/iOS/Flutter) ใช้ SpannableString / AttributedString / TextSpan ได้โดยตรง — ไม่มีปัญหา combining mark เหมือนบน Web เพราะ native text rendering จัดการสีแยก code point ได้ถูกต้อง
    ⚠️ หมายเหตุ Web:
    บน Web browser, Thai combining marks (ิ ี ึ ื ุ ู ั ็ ์) ไม่สามารถเปลี่ยนสีแยกจากพยัญชนะได้ผ่าน CSS <span> — ต้องใช้ Canvas rendering (ดู SKILL.md Section 6.5)

    🎓 Logic & Algorithms สำหรับ Mobile

    เมื่อผู้ใช้กรอก lastname ระบบจะคำนวณเลขศาสตร์ของนามสกุลนั้น และนำมารวมกับเลขศาสตร์ของชื่อที่ค้นหาได้ในผลลัพธ์ คืนค่ามาในฟิลด์ total_sat และ total_sha

    กลยุทธ์การค้นหาแบบ Fallback (3 Levels)

    เพื่อไม่ให้แอปแสดงผล "ไม่พบข้อมูล" บ่อยเกินไป ระบบมีกลยุทธ์การค้นหาดังนี้:

    1. Level 1 (Strict): ค้นหาชื่อที่มีความหมายตรงกัน และต้องมีเลขศาสตร์ดีทั้ง Sat, Sha และไม่มีกาลกิณี
    2. Level 2 (Relaxed): หากไม่พบ จะลดระดับเงื่อนไขเป็นชื่อที่มีเลขศาสตร์ดีอย่างใดอย่างหนึ่ง (Sat OR Sha)
    3. Level 3 (Desperate): หากยังไม่พบอีก จะแสดงชื่อที่มีความหมายตรงที่สุดโดยละทิ้งเงื่อนไขเลขศาสตร์ดีทั้งหมด (แต่ยังคงกาลกิณีไว้หากเลือกกรอง)

    กฎตัวเลข 3 หลัก (> 100)

    ในกรณีที่ total_sat หรือ total_sha มีค่าเกิน 100 ตามศาสตร์ปกติจะไม่มีคำทำนายโดยตรง Mobile App ควรใช้หลักการ "แยกคู่" ในการแสดงผล:

    • เลข 107 → คู่หน้าคือ 10 และ คู่หลังคือ 07
    • Mobile ควรเรียก /api/v1/number-meaning 2 ครั้ง (แยกตามคู่) เพื่อนำคำทำนายมาแสดงคู่กัน
    💡 Tip: ทางฝั่ง Mobile สามารถ Check ความยาวของตัวเลขได้เลย หาก > 100 ให้เปิด UI ลูกเล่นการวิเคราะห์เป็นคู่เพื่อความพรีเมียม

    5. Name Keywords & Hybrid Search (AI)

    GET /api/v1/name-keywords

    วิเคราะห์รากศัพท์ ความหมายแฝง และสกัด Keywords ของชื่อด้วย AI พร้อมค้นหา 15 ชื่อมงคลที่มีความหมาย+รากศัพท์คล้ายกัน (Hybrid Vector + Trigram Search)

    Query Parameters

    Field Type Required Description
    name string required ชื่อที่ต้องการวิเคราะห์ (เช่น "ณเดชน์")
    good_sat bool optional true = บังคับกรองเฉพาะรายชื่อ (similar) ที่มีเลขศาสตร์ดี
    good_sha bool optional true = บังคับกรองเฉพาะรายชื่อ (similar) ที่มีพลังเงาดี

    Response Body (JSON)

    Field Type Description
    name string ชื่อที่ส่งเข้ามาตอนค้นหา
    roots string คำอธิบายรากศัพท์หรือพยางค์ของชื่อ (เช่น "ณ เดช เดชน์")
    meaning_summary string ความหมายสรุปจากการวิเคราะห์ของ AI
    keywords string[] ป้ายกำกับคำสำคัญ (เช่น ["กล้าหาญ", "มีอำนาจ"])
    similar object[] รายชื่อที่คล้ายกัน 15 อันดับ (เรียงตามคะแนนความคล้าย final_rank)

    similar[] Object

    Field Type Description
    name string ชื่อภาษาไทย (ที่ใกล้เคียงกับความหมายและรากศัพท์)
    meaning string ความหมายของชื่อ
    gender string เพศ (ช = ชาย, ญ = หญิง, ค = คละ)
    sat_sum / sha_sum int ผลรวมเลขศาสตร์ / พลังเงาของชื่อ
    root_score float ความคล้ายด้านตัวอักษร (Trigram) 0 ถึง 1
    semantic_score float ความคล้ายด้านความหมาย (Vector) 0 ถึง 1
    final_rank float คะแนนความคล้ายรวม (40% roots + 60% semantic) ไว้สำหรับเรียง

    8. ตัวอย่าง Android (Kotlin)

    // Data Classes
data class KakiChar(val char: String, val is_kaki: Boolean)
data class NameResult(
    val name: String,
    val meaning: String,
    val sat_sum: Int,
    val sha_sum: Int,
    val is_sat_good: Boolean,
    val is_sha_good: Boolean,
    val kaki_highlight: List<KakiChar>
)

// Render highlighted name using SpannableString
fun buildHighlightedName(result: NameResult): SpannableString {
    val spannable = SpannableString(result.name)
    var offset = 0
    for (kaki in result.kaki_highlight) {
        val len = kaki.char.length
        if (kaki.is_kaki) {
            spannable.setSpan(
                ForegroundColorSpan(Color.parseColor("#ef4444")),
                offset, offset + len,
                Spannable.SPAN_EXCLUSIVE_EXCLUSIVE
            )
        }
        offset += len
    }
    return spannable
}

// Usage in RecyclerView / Compose
textView.text = buildHighlightedName(result)

// --- Jetpack Compose version ---
@Composable
fun HighlightedName(result: NameResult) {
    val annotated = buildAnnotatedString {
        for (kaki in result.kaki_highlight) {
            if (kaki.is_kaki) {
                withStyle(SpanStyle(color = Color(0xFFEF4444))) {
                    append(kaki.char)
                }
            } else {
                append(kaki.char)
            }
        }
    }
    Text(text = annotated, fontWeight = FontWeight.Bold, fontSize = 18.sp)
}

    9. ตัวอย่าง iOS (Swift)

    struct KakiChar: Codable {
    let char: String
    let is_kaki: Bool
}

// Build NSAttributedString with per-character coloring
func buildHighlightedName(highlights: [KakiChar]) -> NSAttributedString {
    let result = NSMutableAttributedString()
    let normalAttrs: [NSAttributedString.Key: Any] = [
        .foregroundColor: UIColor.white,
        .font: UIFont.boldSystemFont(ofSize: 18)
    ]
    let kakiAttrs: [NSAttributedString.Key: Any] = [
        .foregroundColor: UIColor(red: 0.94, green: 0.27, blue: 0.27, alpha: 1), // #ef4444
        .font: UIFont.boldSystemFont(ofSize: 18)
    ]
    for item in highlights {
        let attrs = item.is_kaki ? kakiAttrs : normalAttrs
        result.append(NSAttributedString(string: item.char, attributes: attrs))
    }
    return result
}

// Usage
label.attributedText = buildHighlightedName(highlights: result.kakiHighlight)

// --- SwiftUI version ---
struct HighlightedName: View {
    let highlights: [KakiChar]
    var body: some View {
        highlights.reduce(Text("")) { result, item in
            result + Text(item.char)
                .foregroundColor(item.is_kaki ? Color(hex: "#ef4444") : .white)
        }
        .font(.system(size: 18, weight: .bold))
    }
}

    11. Name Keywords Lab — Hybrid Search + Kaki Highlight

    GET /api/v1/name-keywords

    ค้นหาชื่อมงคลด้วย Hybrid Search (Trigram 40% + Vector AI 60%) พร้อมคำนวณ Auspicious Bonus และ Length Adjust แล้ว rank ได้ Top 15 เมื่อระบุ day จะ return kaki_chars ในทุกชื่อ — Mobile ใช้ highlight ตัวอักษรกาลกิณีได้ทันที

    Ranking Score Formula

    final_rank = (root_score × 0.4) + (semantic_score × 0.6)
           + auspicious_bonus   // D10=+0.15, D8=+0.10, D5=+0.05
           + length_adjust      // ≤ 6 chars=+0.07, > 12 chars=-0.05

    Flutter — Highlight kaki_chars (ไม่ต้อง per-char API)

    // Response มี kaki_chars: ["า", "์"] เลย — ไม่ต้อง call API แยก
Widget buildNameWithKaki(String name, List<String> kakiChars) {
  final kakiSet = Set<String>.from(kakiChars);
  final chars = name.characters.toList(); // package:characters
  return RichText(
    text: TextSpan(
      style: const TextStyle(fontSize: 18, fontWeight: FontWeight.bold),
      children: chars.map((cluster) {
        final isKaki = cluster.codeUnits.any(
          (c) => kakiSet.contains(String.fromCharCode(c))
        );
        return TextSpan(
          text: cluster,
          style: TextStyle(color: isKaki ? const Color(0xFFEF4444) : Colors.white),
        );
      }).toList(),
    ),
  );
}

// Usage
buildNameWithKaki(item.name, item.kakiChars)

    Kotlin (Android) — Highlight kaki_chars

    fun buildHighlightedSpan(name: String, kakiChars: List<String>): SpannableString {
    val kakiSet = kakiChars.toSet()
    val span = SpannableString(name)
    name.indices.forEach { i ->
        val ch = name[i].toString()
        if (kakiSet.contains(ch)) {
            span.setSpan(
                ForegroundColorSpan(Color.parseColor("#EF4444")),
                i, i + 1, Spannable.SPAN_EXCLUSIVE_EXCLUSIVE
            )
        }
    }
    return span
}

// Usage
textView.text = buildHighlightedSpan(item.name, item.kakiChars)
