Astro Calendar API Documentation

API สำหรับคำนวณวันมงคลและวันอัปมงคลตามหลักโหราศาสตร์ไทย

GET

วันฟู (Foo Days)

คำนวณวันฟู - วันมงคลสูงสุดตามเดือนจันทรคติและวันในสัปดาห์ เหมาะสำหรับการเริ่มต้นงานใหม่ ขึ้นบ้านใหม่ หรือจัดงานมงคล

http://localhost:8095/api/foo-days
http://localhost:8095/api/foo-days/2026

Parameters

Parameter Type Description
year (optional) integer ปีที่ต้องการ (default: ปีปัจจุบัน)

Example Request

# วันฟูปีปัจจุบัน
curl http://localhost:8095/api/foo-days

# วันฟูปี 2026
curl http://localhost:8095/api/foo-days/2026
// Response will appear here
GET

วันกาลกิณี (Kalagni Days)

คำนวณวันกาลกิณี - วันอัปมงคลตามวันเกิด ควรหลีกเลี่ยงการทำกิจกรรมสำคัญในวันเหล่านี้

http://localhost:8095/api/kalagni?birth_day=อาทิตย์
http://localhost:8095/api/kalagni/age?birth_day=อาทิตย์&age=45

Parameters

Parameter Type Description
birth_day string วันเกิด (อาทิตย์, จันทร์, อังคาร, พุธ, พฤหัสบดี, ศุกร์, เสาร์, พุธ กลางคืน)
age (optional) integer อายุสำหรับคำนวณแบบพิเศษ

Example Request

# วันกาลกิณีพื้นฐาน
curl "http://localhost:8095/api/kalagni?birth_day=อาทิตย์"

# วันกาลกิณีตามอายุ
curl "http://localhost:8095/api/kalagni/age?birth_day=อาทิตย์&age=45"
// Response will appear here
GET

สิทธิโชค (Sitti Chok Days)

คำนวณวันสิทธิโชค, มหาสิทธิโชค, และชัยโชค วันที่นำโชคนำความสำเร็จมาให้

http://localhost:8095/api/sitti-chok
http://localhost:8095/api/sitti-chok?year=2026

Parameters

Parameter Type Description
year (optional) integer ปีที่ต้องการ (default: ปีปัจจุบัน)

Example Request

# วันสิทธิโชคปีปัจจุบัน
curl http://localhost:8095/api/sitti-chok

# วันสิทธิโชคปี 2026
curl "http://localhost:8095/api/sitti-chok?year=2026"
// Response will appear here
